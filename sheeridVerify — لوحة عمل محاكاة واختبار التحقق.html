دليل البنية والواجهات البرمجية (sheeridVerify)

يعتمد المشروع الأصلي على Node.js ≥ 22.15 مع متصفح Camoufox لتعبئة النماذج واستخدام واجهة fetch المدمجة للاستعلام عن الحالة ورفع المستندات دون تعديلها. تحاكي هذه الصفحة واجهة الويب المحلية (http://127.0.0.1:8787) بالكامل داخل المتصفح.

نقاط النهاية (REST API)

  • GET /api/session → X-Local-Token
  • POST /api/jobs → Enqueue job
  • POST /api/jobs/:id/cancel → Stop job
  • POST /api/jobs/:id/resume → Re-queue
  • DELETE /api/jobs/:id → Remove history

أوامر سطر الأوامر (CLI)

  • npm run web # Start local workbench
  • npm start # Fill form without submit
  • npm run status # One-shot status check
  • npm run submit -- --file proof.png
  • npm test # Run mock test suite
